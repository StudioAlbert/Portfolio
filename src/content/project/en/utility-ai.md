Course material on **Utility AI**: a decision-making approach where every action receives a continuous score computed through a **response curve** (linear, quadratic, logistic…). The NPC then picks the action with the best score.

## Things to try

- Adjust the curve parameters and watch the effect on the score.
- Compare curve families to understand when to use each one.

The playable demo is embedded on this page (`demoUrl` field). Source code: see the repo link.
