Commissioned by SNCF (the French national railway company) — an exact replica of the air distribution system used for railway braking. The simulator lets technicians prepare to handle the system before working on real equipment.

## Tech

- Unity, gameplay programming and simulation logic
- 3D modelling and instructional UI
- Validated with SNCF domain experts
